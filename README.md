# NSU_CAPSTONE

졸업작품 4인 개발팀용 단일 Repository 초기 운영 스캐폴드입니다.

- Repository: `nsuCapstoneTeam/NSU_CAPSTONE`
- Repository 소유자: `nsuCapstoneTeam` Organization
- 개발 인원: Frontend 2명 + Backend 2명
- Git 전략: **GitHub Flow**
- 장기 브랜치: **`main` 하나**
- Merge 방식: **Squash Merge**
- 업무 추적: Linear Issue ID 사용 예정
- AI 개발 지원: Claude Code / Claude Tag / Linear Coding Sessions 사용 예정
- PR 리뷰: CodeRabbit + Human Review 사용 예정

## 핵심 원칙

```text
Slack
= 대화 / 회의

Linear
= 업무와 일정 Source of Truth

GitHub
= 코드 Source of Truth

Claude
= 업무 정리 / 개발 보조

CodeRabbit
= AI 보조 Reviewer

Human
= 최종 승인 / Merge
```

```
Slack #dev
   ↓
Thread 팀 논의
   ↓
@Claude
   ↓
논의 요약 / 문서 초안 / 설계 검토
   ↓
사람 검토
   ↓
Linear
   ↓
작업 Branch
   ↓
AI Agent 또는 Human 구현
   ↓
GitHub PR
   ↓
GitHub Actions + CodeRabbit
   ↓
Human Review
   ↓
Squash Merge
   ↓
Linear 상태 정리
```
