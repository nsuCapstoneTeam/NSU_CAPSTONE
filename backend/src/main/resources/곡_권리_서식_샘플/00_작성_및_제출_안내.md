# 곡 업로드 권리 서식 — 작성 및 제출 안내

버전: v0.2 · 작성 기준일: 2026-10-22 · 개정: 2026-11-05(운영자 검토 단계를 빼고, 업로드 때 서버 검증과 신고 대응으로 바꿈)

## 1. 이 서식의 용도

이 서식은 **① 아티스트가 업로드 전에 권리를 확보하고 서류를 준비 → ② 업로드 때 서버가 서류 첨부·형식만 검증하고 분석·추천·미리듣기 시작 → ③ 신고·중단·소명·재개 처리**라는 운영 방식을 위한 초안입니다. 운영자는 서류의 진위와 허락 범위를 심사하지 않습니다(2026-11-05 결정).

대한민국 서비스를 전제로 작성한 **법률 검토용 초안**입니다. 정부의 공식 표준서식이나 법률 전문가가 검토를 마친 문서는 아닙니다. 서류를 받는 것만으로 플랫폼의 법적 책임이 없어지지는 않습니다. 실제 이용 방법이 허락 범위 안에 있어야 하고, 권리 신고가 오면 4절 3단계 절차를 지켜야 합니다.

아티스트가 필요한 권리를 모두 직접 보유하고 제한이 없다면 01번으로 본인 권리의 이용허락을 받을 수 있습니다. 같은 사람이 같은 권리에 대해 02번을 중복 작성할 필요는 없습니다. 제3자의 권리가 있으면 권리자별 02번이나 **같은 대상·권한·이용 범위를 확인할 수 있는 기존 계약**을 받습니다. 기존 허락이 이미 충분하면 이 서식으로 다시 서명받을 필요는 없습니다.

## 2. 배포 전에 운영자가 확정할 항목

- **실제 계약 당사자:** 서비스명과 운영자의 법적 성명·법인명은 구분합니다. 팀명만 적고 누가 계약상 의무를 부담하는지 비워 두지 않습니다.
- **허락 범위:** CLAP 분석·추천, 사이트 내 직접 미리듣기, 외부 링크·공식 플레이어 중 실제 제공할 항목을 선택합니다. 체크하지 않은 항목은 이용하지 않습니다.
- **기간·지역·대가:** 업로드로 보관이 시작되는 날짜부터 이용 기간을 정합니다. 서비스 접근 지역과 서버 처리 국가를 따로 적습니다. 무료 허락은 명시적으로 선택합니다.
- **보관·삭제:** 원본·변환본, embedding·추천용 데이터, 백업, 권리 증빙의 기간을 구분합니다. 서비스 종료 후 필요한 자료만 적법한 근거로 보관합니다. ‘분쟁 대비’만 적고 무기한 보관하지 않습니다.
- **처리 업체:** 클라우드·외부 AI 처리 업체의 법적 명칭, 업무, 전달 자료와 국가를 적습니다. 같은 운영자 내부 서버와 별도 사업자의 처리를 구분합니다.
- **연락 창구:** 권리 문의·침해 신고 담당자, 연락처와 처리 절차를 사이트에 공개합니다.
- **개인정보:** 서식은 권리 문서에 포함된 최소 정보의 처리 안내를 포함합니다. 음원에 담긴 식별 가능한 음성, 공개 크레딧 및 개인과 연결되는 분석 정보의 처리도 서비스 개인정보 처리방침에 명시합니다. 별도 동의가 필요한 수집·제공·국외 이전 등은 별도 법적 근거와 고지·동의를 마련합니다. 아티스트의 동의로 모든 제3자의 개인정보 처리를 해결한 것으로 보지 않습니다.

두 서식의 기간·지역·구간·처리 업체·대가 조건을 일치시킵니다. 서버는 서류 내용을 읽지 않아 곡마다 다른 허락 범위를 적용할 수 없습니다. 그래서 허락서는 서비스의 이용 범위(보관, CLAP 분석·추천, 서비스 내 미리듣기) 전체를 허락해야 합니다. 그렇지 않은 곡은 올리지 않도록 아티스트에게 안내합니다.

이 초안은 권리자 또는 아티스트의 요청에 따른 장래 이용 종료를 허용합니다. 유상 계약을 쓰는 경우에는 중도 종료 정산을 함께 정해야 합니다. 아직 결정하지 않은 조건은 빈칸으로 남겼으며, **빈칸이 있는 상태로 서명을 받거나 제출하지 않습니다.** 서버는 빈칸을 확인하지 않으므로 이 확인은 아티스트의 책임입니다.

## 3. 곡 종류별 준비 예시

| 제출 형태 | 아티스트가 확인할 사항 | 준비할 자료 예시 |
| --- | --- | --- |
| 혼자 작사·작곡·연주·녹음한 자작곡 | 공동 권리·외부 소재·신탁·양도·독점계약 유무 | 업로드 화면의 01번 동의 |
| 공동 창작 또는 다른 사람의 연주가 포함된 자작곡 | 공동 권리의 행사 요건, 각 참여자의 권한, 녹음물 권리 | 01번 동의 + 필요한 권리자들의 02번 또는 기존 계약 |
| 직접 연주·녹음한 커버곡 | 원곡의 작사·작곡 권리와 실연·녹음물 권리를 각각 확인. 편곡·개사가 있으면 필요한 변경 허락도 확인 | 원곡 권한자의 이용허락 + 참여자·녹음물 관련 허락 |
| 외부 MR·비트·샘플을 사용한 곡 | 원곡뿐 아니라 사용한 녹음물·실연·소재의 라이선스 조건 | 소재별 라이선스 본문·취득 내역 + 부족한 범위의 별도 허락 |
| 보호기간이 끝난 원곡을 사용한 곡 | 해당 국가의 보호기간과 대상 원곡을 확인. 새 편곡·실연·녹음물의 권리는 별도 확인 | 근거 자료 + 남아 있는 권리의 허락 |
| CC 등 공개 라이선스가 적용된 곡 | 정확한 버전, 권리자, 상업적 이용·변경·표시 조건, 라이선스 적용 대상 | 원문·출처·확인일 및 서비스 이용과 조건의 대조 기록 |

‘자작곡’, ‘커버곡’, ‘저작권 문제 없음’이라는 표시 자체가 권리를 증명하지는 않습니다. 구매 영수증, 저작권 등록증, YouTube 게시 화면만으로 이 서비스의 분석·복제·전송까지 허락받았다고 판단하지 않습니다. 모든 자작곡에 저작권 등록증을 일률적으로 요구하는 것도 이 서식의 조건이 아닙니다.

업로드 화면에서 '제3자 권리 있음'을 고르면 02번이나 같은 범위의 기존 계약서를 파일로 함께 올립니다. 서버는 첨부 여부와 형식만 확인합니다.

커버 녹음의 제작·편곡·개사나 기존 녹음물의 취득 자체에 필요한 권한도 확인합니다. 이 서식은 이미 있었던 무단 제작·취득을 소급해 해결하는 합의서가 아닙니다.

## 4. 3단계 운영 절차

### 1단계 — 업로드 전 확보, 제출 시 특정

1. 아티스트에게 실제 이용 범위와 서식·개인정보 처리 안내를 먼저 제공합니다.
2. 아티스트는 필요한 권리자의 허락을 **음원 제출 전에** 확보합니다. 권한이 불분명하면 음원을 올리지 않습니다.
3. 기간·지역·대가 등 조건을 확정하고 서명 또는 전자 동의를 받습니다. 미리 체크된 동의란이나 빈칸을 동의로 간주하지 않습니다.
4. 서버는 동의 기록(문구 버전·시각), 첨부 허락서, 곡 식별자, 파일 해시를 연결해 기록합니다.
5. 접수한 서류는 비공개로 보관하고 서비스 화면으로는 열람하지 않습니다.

### 2단계 — 업로드 때 서버 검증

서버는 다음만 검사합니다. 통과하면 바로 저장하고 CLAP 분석·추천·미리듣기에 씁니다.

- 01번 동의 문구가 지금 버전인지
- '제3자 권리 있음'을 고른 곡에 이용허락서가 1개 이상 첨부됐는지(최대 5개)
- 이용허락서가 PDF·JPEG·PNG이고 파일당 5MiB 이하인지
- 음원의 형식·크기·길이(곡 업로드 검사)

서버와 운영자는 서명한 사람의 권한, 파일과 허락서의 일치, 허락 범위를 심사하지 않습니다. 그 확인은 서류를 준비한 아티스트의 책임이며(01번 동의서), 권리 문제는 3단계 신고 절차로 처리합니다.

‘검증 통과’는 형식 검사를 통과했다는 기록입니다. 권리의 존재나 침해 부존재를 인증하는 표현으로 사용하지 않습니다.

### 3단계 — 신고 대응

1. **신고 수령인 공지:** 권리 문의·침해 신고를 받을 담당자와 연락처를 사이트에 공개합니다(저작권법 제103조 제4항). 사이트에서 신고 대상 곡, 요청 내용, 권리 근거와 연락처를 접수합니다. 법정 신청·증빙 요건은 현행 법령에 맞춥니다.
2. **즉시 중단:** 저작권법 제103조에 따른 중단 요구를 받으면 그 곡을 바로 멈춥니다. 새 재생 주소를 발급하지 않고, 이미 발급한 재생 주소도 쓸 수 없게 하며, 추천·다시 보기와 새 분석 작업에서 뺍니다. 캐시·진행 중 작업·저장된 추천 결과에도 중단 상태를 반영합니다.
3. **양쪽 통보:** 중단 사실을 신고자(권리주장자)와 곡을 올린 아티스트에게 알립니다(제103조 제2항).
4. **소명하면 재개:** 아티스트가 정당한 권리를 소명해 재개를 요구하면, 재개 요구 사실과 재개 예정일을 신고자에게 알리고 그날 재개합니다. 예정일 전에 신고자가 소송을 제기했다고 알리면 재개하지 않습니다(제103조 제3항). 세부 요건과 시기는 하위 법령을 함께 확인합니다. 임의의 ‘재동의 버튼’으로 바로 복구하지 않습니다.
5. **반복 침해 계정 정지:** 중단이 확정된 곡이 정해진 수를 넘은 계정은 정지합니다(제102조 제1항 제1호 다목). 기준 수와 해제 절차는 약관·운영 정책에 공개합니다.

운영자는 신고 내용의 옳고 그름을 판단하지 않고 위 순서대로 처리합니다. 조치와 통지 기록을 남기고, 보존이 필요한 자료는 적법한 근거·기간을 정해 접근을 제한합니다. 허락 만료·철회·파일 교체도 같은 흐름으로 처리합니다.

이 운영 절차만으로 저작권법상 온라인서비스제공자 책임 제한 요건이 자동으로 충족되는 것은 아닙니다. 서비스의 실제 역할과 각 법정 요건을 따로 검토해야 합니다.

## 6. 서비스 문서·시스템에 반영할 사항

이 파일들은 서식 초안입니다. 이 서식에 맞춘 설계는 ADR `music_upload/01`·`02`와 곡 API(`docs/api/04_music.md` §2)에 있고, SSOT 반영은 v1.17 초안(승인 대기)입니다. 적용 전에 다음 사항을 함께 맞춰야 합니다.

- 권리 문서는 비공개로 보관하고 서비스 API로는 열람하지 않음. 분쟁 때 운영 담당 역할만 열람하는 최소 권한.
- 중단·만료 상태에 따른 분석·추천·재생 제어.
- 정확한 파일과 동의·허락서 버전의 연결, 교체·중복 제출 시 새 동의 기록 보존.
- 권리 만료·철회 시 원본뿐 아니라 embedding·추천 결과·재생 접근 권한 처리.
- 개인정보 처리방침, 약관, 외부 처리 계약, 신고·재개 절차와 담당자 공개.

서식은 분석용 파일의 직접 제출을 전제로 합니다. 외부 미리듣기를 선택해도 YouTube 등에서 음원을 다운로드해 분석하는 권한이 생기지는 않습니다. ‘30초’, ‘60초’라는 길이 자체를 면책 조건으로 쓰지 않습니다.
