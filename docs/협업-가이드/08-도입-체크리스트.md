# 도입 체크리스트

← [가이드 목차](README.md)

이 목록은 적용 상태를 추적하기 위한 것이다. 문서 작성만으로 체크하지 않는다.

- [ ] 팀원이 본 가이드의 기존 규칙과 새 권장 운영값을 검토했다.
- [x] 운영 가이드를 `docs/협업-가이드/`에 주제별 문서로 추가했다.
- [ ] `.gitmessage.txt`를 저장소에 추가했다.
- [ ] 저장소 소유자가 Squash 방식과 `main` 보호 설정을 적용했다.
- [ ] 팀원 모두 자신의 clone에 초기 설정을 적용하고 결과를 확인했다.
- [ ] CI 워크플로의 실제 실행을 검증한 뒤 필수 검사로 등록했다.
- [ ] 작은 문서 PR로 작성 → 검증 → 다른 사람 승인 → Squash Merge를 수행했다.
- [ ] 최종 커밋 메시지와 원격 브랜치 정리까지 확인했다.
- [ ] Slack `#dev`에 문서 링크와 초기 설정 방법을 공지했다.

`.github/pull_request_template.md`는 저장소에 이미 있다. `.gitmessage.txt`는 아직 없으므로 [커밋 전략과 메시지](03-커밋-전략과-메시지.md#공통-gitmessagetxt-제안)의 템플릿 내용을 별도 PR로 추가한다. README 수정, Slack 게시, 저장소 설정 변경은 아직 실행하지 않았다.
