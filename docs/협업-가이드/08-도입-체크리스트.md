## 이 문서 정리 PR에서 반영

- [ ] 단일 `.github/pull_request_template.md`를 제거한다.
- [ ] 문서용 `.github/PULL_REQUEST_TEMPLATE/문서_PR.md`를 `main`에 반영한다.
- [ ] 구현용 `.github/PULL_REQUEST_TEMPLATE/구현_PR.md`를 `main`에 반영한다.
- [ ] 최신 Slack → Claude → Linear → GitHub 개발 흐름을 협업 가이드에 반영한다.

위 네 항목은 현재 문서 정리 PR이 `main`에 Squash Merge된 뒤 체크한다.
