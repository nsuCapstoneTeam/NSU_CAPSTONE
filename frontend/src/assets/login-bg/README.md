# 로그인 배경 사진

이 폴더에 넣은 사진이 로그인 화면 배경에 자동으로 순서대로 나옵니다.
(파일 이름 순서: `01-stage.webp`, `02-crowd.webp` … 처럼 번호를 붙이면 순서를 정할 수 있어요.)

- 형식: `.webp`(권장), `.jpg`, `.jpeg`, `.png`, `.avif`
- 크기: 가로 1920px 정도, **한 장 300KB 안팎**으로 압축 (예: squoosh.app)
- 장수: 4~5장 권장
- **저작권**: 직접 찍은 사진이나 Unsplash·Pexels처럼 무료 상업 이용이 허용된 사진만 사용하세요.
  출처를 모르는 검색 이미지는 사용하지 않습니다.
- 사진이 하나도 없으면 임시 무대 조명 그라데이션이 대신 나옵니다.
